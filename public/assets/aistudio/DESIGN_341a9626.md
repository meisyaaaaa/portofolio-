## Brand & Style

This design system expresses an **Editorial Brutalist Zine and Scrapbook Poster** aesthetic. It bridges the precision of technical robotics with the tactile, expressive chaos of physical DIY publication design.

### Core Attributes
- **Tactile & Physical:** Surfaces recall physical craft poster board, blueprint graph paper, masking tape strips, and printed stickers.
- **Engineered Rawness:** Stark carbon black borders, heavy contrast rules, hard offset geometry, and interactive CAD/Figma canvas cues (bounding boxes, anchor nodes, coordinate readouts).
- **Expressive Dynamism:** Organic rotation angles (`-3deg` to `+2.5deg`), stark cutouts, ticker marquees, and high-impact accent punches.

### Emotional Target
The user experience should feel like flipping through an obsessively documented personal lab binder—uncompromisingly bold, technically credible, playful, and distinctively physical.

## Colors

The palette simulates real print on craft paper: high-density carbon ink, stark signal accents, blueprint guide lines, and vector selection primitives.

### Palette Architecture
- **Paper Canvas (`#F2F1ED`):** The foundational substrate. Warm, tactile, non-sterile off-white.
- **Carbon Ink Primary (`#111111`):** Heavy structure, primary typography, hairline graph guides, stark fills, and solid shadows.
- **Muted Ink (`rgba(17, 17, 17, 0.68)`): Secondary metadata, supporting copy, and structural secondary rules.
- **Signal Red-Orange (`#E8392B`):** Hard drop shadows, die-cut sticker badges, callouts, starburst graphics, and active interactive borders.
- **Selection Blue (`#2B7FFF`):** Viewport selection overlays, node points, transform coordinates, and inspector labels.
- **Graph Grid (`rgba(17, 17, 17, 0.065)`): Structural 26px drafting matrix overlaid on the canvas.
- **Masking Tape (`rgba(226, 222, 212, 0.85)`): Translucent structural fasteners anchoring media to cards.

### Functional Roles
Color is not applied via soft blurs or gradients; it is applied via hard flats, stark stroke definitions, and tactile overlay fills.

## Typography

Typography establishes an industrial editorial rhythm: dense, monospace, mechanical headings paired with rigorous engineering annotations.

### Typographic Hierarchy
- **Display & Headings:** Set in heavy, tight-tracked `Space Grotesk`. Headings use uppercase transformations for display statements and section dividers to evoke printed woodblock and poster typesetting.
- **Body & Content:** Set in mid-weight `Space Grotesk` to maintain mechanical clarity with comfortable paragraph readability.
- **Specifications, Badges & Metadata:** Set strictly in `Space Mono`. All coordinates, tool markers, hardware registers, and dimension readouts remain monospaced and structured.
- **Annotation Accents:** Hand-drawn notes, dynamic directional arrows, and marginalia use cursive script accents (`Caveat`, 700 weight) with slight rotational offsets (`-4deg` to `+2deg`) positioned alongside primary specs.

## Layout & Spacing

The layout simulates a tactile canvas over a strict drafting grid.

### Layout Mechanics
- **Base Grid Substrate:** The canvas is grounded by a visible 26px graph-paper pattern (`26px x 26px` background size with `--grid: rgba(17, 17, 17, 0.065)`).
- **Column System:** Desktop layout operates on a 12-column structure with `1.5rem` gutters and `2.5rem` outer margins. Content aligns both strictly to grid axes or intentionally overlaps adjacent boundaries to emulate collage layers.
- **Breakpoints:**
  - **Desktop (1024px+):** Full 12-column layout; multiple overlapping card planes; active transformation margins.
  - **Tablet (768px – 1023px):** 8-column layout; card rotations reduce to `< 1.5deg`; horizontal marquee ribbons scale linearly.
  - **Mobile (320px – 767px):** 4-column layout; gutters reduce to `1rem`; margins drop to `1rem`; rotations are constrained to zero or `-1deg` max to prevent viewport clip overflow.

## Elevation & Depth

This system rejects soft blurs, diffuse shadows, and standard ambient lighting. All depth is physical, mechanical, and hard-edged.

### Hard Offset Shadows
Depth is achieved via stark, unblurred black or accent color projections:
- **Level 1 (Tokens / Chips):** `2px 2px 0 #111111`
- **Level 2 (Cards / Interactive Blocks):** `4px 4px 0 #111111` or `4px 4px 0 #E8392B`
- **Level 3 (Modals / Floating Palettes):** `8px 8px 0 #111111`

### Interaction States
Interactive components actively shift on press and hover:
- **Hover:** Translation of `translate(-2px, -2px)` with shadow expanding from `4px 4px` to `6px 6px`.
- **Active / Pressed:** Translation of `translate(2px, 2px)` with shadow collapsing to `0px 0px 0`.

### Physical Layering & Overlays
- **Tape Strips:** Semi-opaque rectangular patches (`background: rgba(226, 222, 212, 0.85)`) pinned diagonally across corners or top edges of polaroid modules.
- **Die-Cut Sticker Outlines:** High-contrast multi-directional borders created with hard CSS filters:
  `filter: drop-shadow(2px 0 0 #E8392B) drop-shadow(-2px 0 0 #E8392B) drop-shadow(0 2px 0 #E8392B) drop-shadow(0 -2px 0 #E8392B);`
- **Torn Edges:** Jagged separators utilize polygon clip-paths (`polygon(0 0, 100% 0, 100% calc(100% - 10px), ... 0 100%)`) to break strict horizontal dividers.

## Shapes

The geometric framework is strictly zero-radius (`roundedness: 0`). 

- **Primary Geometry:** Sharp, right-angled rectangles across all standard UI containers, input elements, buttons, and framing boxes.
- **Exceptions (Intentional Die-Cuts):** Badges and stickers use circular, starburst, or polygonal profiles, but retain crisp, unrounded edges at vertices.
- **Rotations:** Non-standard orientations (`-3deg` to `+2.5deg`) are applied via CSS transforms to scrap elements, simulating real physical pinning without rounding corners.

## Components

### 1. Buttons
- **Brutalist Action Button:** Hard `#111111` background, `#F2F1ED` text, zero radius, `1.5px solid #111111`. Shadow: `4px 4px 0 #E8392B`. Hover translates `translate(-2px, -2px)` with shadow expanding to `6px 6px 0 #E8392B`. Active state translates `translate(2px, 2px)` with zero shadow.
- **Secondary Wire Button:** Background transparent, `#111111` text, `2px solid #111111`, with `3px 3px 0 #111111` shadow.

### 2. Figma / Blueprint Selection Canvas
- **Selection Bounding Box:** Encloses active project features with a `1.5px solid #2B7FFF` perimeter stroke.
- **Control Handles:** Eight square handles (`7px x 7px`, `#FFFFFF` fill, `1.5px solid #2B7FFF`) placed on the corners and edge centers.
- **Dimension Badge:** Floating coordinate flag placed top-left or bottom-right: `#2B7FFF` background, `#FFFFFF` text, `font-family: 'Space Mono'`, `10px`, uppercase (`e.g., W: 320px × H: 490px`).

### 3. Scrapbook Polaroid Card
- **Frame:** Solid white `#FFFFFF` or pale craft `#F9F8F5` surface enclosed in a `1.5px solid #111111` rule, `12px` padding on sides and top, `32px` padding at base for annotations.
- **Tape Anchor:** Single top-center or dual corner strips with translucent masking tape (`rgba(226, 222, 212, 0.85)`).
- **Physical Tilt:** Subtle static rotation between `-1.8deg` and `+1.5deg`.
- **Annotation:** Script text or monospaced identifier at the enlarged bottom margin.

### 4. Marquee Band
- **Style:** Full-width strip with `#111111` background and `#F2F1ED` foreground text.
- **Typography:** Alternating solid uppercase bold text and outlined transparent text (`-webkit-text-stroke: 1px #F2F1ED; color: transparent;`).
- **Motion:** Continuous horizontal CSS translate animation running in infinite loop.

### 5. Tech & Competency Badges
- **Structure:** Monospaced label enclosed in a 1px carbon border with hard `2px 2px 0` shadow.
- **Signature Palette Fills:**
  - C++: `#00599C` (white text)
  - Python: `#306998` (white text)
  - HTML/JS: `#E34F26` (white text)
  - Figma: `#1E1E1E` (white text)
  - Canva: `#00C4CC` (black text)
  - After Effects: `#00005B` (light lavender `#9999FF` text)
  - CapCut: `#111111` (white text)
  - MS Office: `#C43E1C` (white text)

### 6. Form Inputs & Checkboxes
- **Text Inputs:** `#F2F1ED` background with `2px solid #111111` border. Active focus shifts border to `#2B7FFF` with hard `3px 3px 0 #2B7FFF` offset. Label set in `Space Mono` uppercase.
- **Checkboxes:** Square `18px x 18px` container, `2px solid #111111`. Checked state displays a solid `#111111` or `#E8392B` fill with an angled "X" marker or stark geometric check.
